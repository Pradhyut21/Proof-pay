# Dataset and asset sources

Status date: 2026-11-24. Part of the source audit ([`source_audit.md`](source_audit.md)).

## What PanelProof data is made of

| Asset | Origin | License / terms | Redistribution |
| --- | --- | --- | --- |
| Panel images | Generated by this repository's 2D renderer (`render.py`) from a seeded scene | Project output; no upstream image is used | Dev samples are committed (`data/demo`, `data/samples`). Frozen test truth stays private |
| Fonts | Pillow's bundled default font, loaded with `ImageFont.load_default(size)`. `assets/fonts/` is empty | Pillow documents this font as Aileron Regular under a permissive license. **Not independently verified** in this audit; confirm from the installed Pillow distribution before release | Glyphs are rasterized into images only; the font file is not shipped |
| Code | This repository | See `LICENSE` | n/a |
| Model weights | None. No model is trained, fine-tuned or bundled | n/a | n/a |
| Mock model outputs | `demo_adapter.py` simulations | Project output | Always labelled **DEMO ONLY** |
| Real instrument photos | None | n/a | n/a |

Code, weights, fonts and image terms are recorded separately above because they differ.

## Optional external slice: MeasureBench (not built)

| Item | Value |
| --- | --- |
| Dataset | `FlagEval/MeasureBench` on Hugging Face |
| Revision seen | `93c001671055f739bc396c73aa6b2d5e6171abed` (last modified 2025-11-03) |
| License | `cc-by-sa-4.0` per dataset card metadata |
| Access | Not gated (the HF API reported `gated: false`) |
| Downloaded or packaged | **No** |

Before anything is downloaded or packaged, all of the following must be decided and written here:

1. **Deterministic selection.** A fixed rule (for example the first N sample ids after sorting by id, N written down)
   so any machine selects the same files.
2. **Attribution.** CC BY-SA 4.0 needs credit to the creators, a license link and a statement of changes.
3. **Share-alike.** Any adapted material distributed with it must carry CC BY-SA 4.0. Decide whether it is
   distributed at all, or only fetched at run time from the original host (recommended: fetch, do not redistribute).
4. **Checksums.** SHA-256 of every selected file, recorded in a manifest next to the selection rule.
5. **Scope.** Single-instrument reading only. Report it as a separate slice; never mix it into the synthetic
   multi-instrument numbers, and never use it to claim real-world transfer for the synthetic set.

Until then, the repository contains no MeasureBench data and `real_slice` stays an empty split.
