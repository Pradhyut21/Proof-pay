# Validation

The verifier reads clean synthetic renders generated by PanelProof. The [independent integration pilot](results/integration_pilot.md) recovered 19 of 20 clean scenes with exact agreement on the 19 recoveries. The older v0.1.0 dataset and perturbation runs below remain as historical evidence. The [candidate validation interface](validation-foundation.md) defines the acceptance checks.

## 1. Acceptance gates for a generated scene

A base scene is accepted only if all of these hold (`export.py`):

1. Layout check passes (`render.check_layout`).
2. The independent raster verifier returns `verified` for every pump, using only the PNG.
3. The verifier's recovered readings agree with the scene truth (`validate.compare_trace_to_scene`).

The historical v0.1.0 build accepted 110 of 120 attempted base scenes (91.7%). Its recorded rejections include 4 unreadable inlet labels, 15 missing-evidence edits, 4 preserving edits, and 2 semantic edits. The acceptance rate for attempted variants was 99.5%. [Historical dataset report](results/dataset_report.json)

- Consistency tasks (n=264) had a maximum shift of **28.0 percentage points**. When ALARM is off, `CONSISTENT` is 64.8% of tasks. When on, `CONTRADICTION` is 63.2%. The v0.2 [balanced X slices](dataset_card.md#current-private-holdout) audit this cue separately from the full cohort.

## 3. Raster verifier under perturbation

`python -m panelproof.cli perturb --dataset data/build/main --limit 30` renders 30 base scenes and applies each perturbation. The scene truth is regenerated from the private seed. [Historical perturbation report](results/perturbation.json)

| Perturbation | Verified correct | Rejected | Verified wrong (false accept) |
| --- | --- | --- | --- |
| none | 30 | 0 | 0 |
| brightness −15% | 30 | 0 | 0 |
| Gaussian blur 0.6 | 30 | 0 | 0 |
| brightness +15% | 26 | 4 | 0 |
| JPEG quality 90 | 19 | 11 | 0 |
| glare over panel | 14 | 16 | 0 |
| scale 0.97 | 10 | 20 | 0 |
| Gaussian noise σ=3 | 0 | 30 | 0 |
| rotation 1° | 0 | 30 | 0 |

Reading the table honestly:

- The recorded run had zero incorrect accepted readings across 270 images. Failures in this sample were verifier rejections.
- The stress test shows fragility outside clean renders. Recovery dropped to 0 of 30 under 1° rotation or sigma-3 noise, 10 of 30 under 0.97 scaling, 14 of 30 with glare, and 19 of 30 for JPEG quality 90.
- The 30-scene sample is small and drawn from the first 30 accepted base groups, so rates have wide uncertainty. Real photographs are out of scope.
- The first run of this study (before the unit table change to psi = 6.894757293168 kPa) reported false accepts under glare. The current run, on the rebuilt dataset, reports none. The scenes and unit table differ between the runs and the cause of the change was not isolated, so the earlier false accepts are not evidence of a fix and glare remains a risk worth re-testing on more scenes.

## Opt-in small-distortion study

This study compared the same 100 accepted base scenes from the audited v0.2 holdout under both verifier modes. The study took the first unique original scenes in exported index order. Each perturbation was applied separately, and Gaussian noise used a reproducible per-image draw. The clean row is a control over scenes that had already passed clean verification.

| Input | Exact recovery with production reader | Exact recovery with opt-in recovery | Opt-in rejections |
| --- | ---: | ---: | ---: |
| Clean | 100 / 100 | 100 / 100 | 0 |
| Gaussian noise σ=3 | 5 / 100 | 58 / 100 | 42 |
| Rotation +1° | 0 / 100 | 64 / 100 | 36 |
| Rotation −1° | 6 / 100 | 66 / 100 | 34 |

Neither mode accepted an incorrect reading on these inputs, including in partly rejected scenes. Exact recovery requires matching gauge ticks, units, indicators, and rule outcomes. The report also records the older one-tick-tolerant comparison as a separate metric. [Aggregate study result](results/small_distortion_study.json)

The opt-in mode estimates a small shared tilt from long perpendicular panel borders. For mild speckle, it cleans the instrument-detection masks while retaining the original reading thresholds. The production dataset, Task Factory, and C3 runner continue to use the clean-render reader. This experiment covers only the three synthetic distortions shown above. Deskewed evidence coordinates refer to the normalized image.

Run the same comparison on the same holdout, once with the optional flag and once without it.

```sh
uv run --project python --python 3.11 --locked python -m panelproof.cli perturb --dataset /local/holdout --limit 100 --workers 4 --axes none gaussian_noise_sigma3 rotate_1deg rotate_minus_1deg --recover-small-distortions --out /local/recovery.json
```

## 5. Human review

`results/human_audit_worksheet.csv` lists 50 tasks sampled across skills for a human reviewer. **No human has reviewed any task.** `results/human_audit_status.json` records zero reviewers and no agreement statistic. Until a person completes the worksheet, task answerability and ambiguity are validated only by the automated checks above.

## Scope of the evidence

Raster agreement covers clean synthetic renders from this generator. The opt-in recovery study covers the listed distortions on its separate 100-scene cohort. The expanded public build establishes coverage of a third layout. Estimating a performance gap between development and frozen splits still requires matched model runs. [Current evidence status](evaluation_results.md)
