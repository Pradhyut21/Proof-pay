# Prior work

- MeasureBench documents measurement-reading errors and provides an optional real component-reading slice. Check attribution and asset terms before adding it. [Paper](https://arxiv.org/abs/2510.26865) · [Repository](https://github.com/flageval-baai/MeasureBench) · [CC BY-SA dataset card](https://huggingface.co/datasets/FlagEval/MeasureBench)
- Compare independent reading and calibration geometry with the ETH gauge reader. [ETH source](https://github.com/ethz-asl/analog_gauge_reader)
- Use CLEVR as a design reference for scene, render and question boundaries. [CLEVR source](https://github.com/facebookresearch/clevr-dataset-gen)
- Use DynaMath as a reference for worst-case group metrics and VLMEvalKit for evaluation adapters. [DynaMath source](https://github.com/DynaMath/DynaMath) · [VLMEvalKit source](https://github.com/open-compass/VLMEvalKit)

The pinned source inventory and full licensing audit are tracked in [#2](https://github.com/Pradhyut21/Proof-pay/issues/2).
