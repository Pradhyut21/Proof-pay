# Innodata Frontier AI Hackathon 2026

PanelProof is planned for Track 2, Visual Task Factory. The public event page lists **6 December 2026** as the deadline and requires **3–4 participants** on a registered team. GitHub currently has two project owners.

| Requirement | Planned evidence |
|---|---|
| Working implementation and repeatability, 25% | Runnable source, setup instructions and a one-command clean-checkout smoke |
| Validity and validation evidence, 25% | Inspectable tasks, deterministic references, independent pixel readings and validation/rejection logs |
| Meaningful variation, 20% | Semantic and nuisance pairs, grouped splits and multiple visual reasoning skills |
| Original approach and engineering judgment, 15% | Source audit, documented design choices, actual model results and limitations |
| Practical impact and communication, 15% | Clear application, scoring demo, failures and a reproducible report |
